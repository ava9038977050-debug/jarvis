# Мультиагентная система Jarvis

## Архитектура

```text
Личный Агент — маршрутизатор
├── Исполнительный директор — оркестратор бизнес-контура
│   ├── HR/BP
│   ├── Юрист
│   ├── Финансы и налоги
│   ├── Эксплуатация недвижимости
│   └── Управленческий контролёр — независимая проверка
└── Авторская мастерская — творческий оркестратор
    ├── Поэт-песенник → Эксперт по тексту
    ├── Композитор → Эксперт по музыке
    └── Аранжировщик-продюсер → Эксперт по фонограмме
```

Оркестраторы задаются локальными `AGENTS.md`. Специализированные роли зарегистрированы в `.codex/agents/*.toml`. Повторяемые профессиональные процессы хранятся как skills внутри соответствующего контура.

## Запуск

- Универсальный Личный Агент: `codex -C "D:/Мои документы/Projects/jarvis"`.
- Исполнительный директор с рабочим архивом: `codex -C "D:/Мои документы/Projects/jarvis/agents/executive-director" --add-dir "D:/Мои документы/Projects/direktor"`.
- Авторская мастерская с рабочим архивом: `codex -C "D:/Мои документы/Projects/jarvis/agents/authors-workshop" --add-dir "D:/Мои документы/Projects/music/Авторская мастерская"`.

В Desktop создайте два локальных проекта с несколькими папками:

- «Исполнительный директор»: основная папка — `jarvis/agents/executive-director`, дополнительная — `direktor`;
- «Авторская мастерская»: основная папка — `jarvis/agents/authors-workshop`, дополнительная — `music/Авторская мастерская`.

Именно основная папка определяет автоматическую загрузку `AGENTS.md`, локальных skills и `.codex/config.toml`; дополнительная папка подключает рабочий архив для поиска, чтения и редактирования. Не делайте архив основной папкой.

Из корня можно явно обратиться к одному из оркестраторов по названию. Если контур нельзя определить достоверно, Личный Агент задаёт одно короткое уточнение и не смешивает профессиональную память.

## Принципы

- Один оркестратор владеет задачей и финальным ответом.
- Один ведущий специалист владеет профессиональным блоком.
- Создание и независимая экспертиза разделены.
- Зависимые этапы выполняются последовательно; параллельность — только для независимой работы.
- Внешние записи и действия, создающие обязательства, выполняются только после подтверждения Юрия.
- `jarvis` — управляющая область; исходные бизнес-документы остаются в `direktor`, творческие — в `music/Авторская мастерская`.

## Ограничения возможностей

Система может анализировать и создавать документы, таблицы, презентации, промпты, музыкальные спецификации и проверять доступные аудиофайлы. Создание полноценной концертной фонограммы требует внешнего музыкального сервиса или DAW; подключение или загрузка в такой сервис не выполняются автоматически.

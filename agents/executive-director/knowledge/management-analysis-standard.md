# Стандарт управленческого анализа

Этот файл применяется вместе с `agents/executive-director/AGENTS.md` для задач по финансовому, объектовому и KPI-анализу. Загружай только относящиеся к задаче разделы исходных данных; не запрашивай весь набор без необходимости.

## Минимальная схема входных данных

Перед расчётом определи отчётную дату или период, валюту, учётный метод и наличие НДС. Запрашивай только отсутствующие поля, необходимые для текущего решения.

| Блок | Минимальные поля |
|---|---|
| Объекты и площади | `object_id`, объект, общая сдаваемая площадь, занятая и вакантная площадь, единица измерения |
| Договоры аренды | `contract_id`, `tenant_id`, объект/помещение, площадь, ставка и её единица, дата начала/окончания, индексация, скидки и арендные каникулы |
| Начисления и оплаты | период, договор/арендатор, вид начисления, сумма, НДС, дата оплаты, оплаченная сумма |
| Дебиторская задолженность | договор/арендатор, документ, дата возникновения, срок оплаты, остаток, количество дней просрочки, спорность |
| OPEX | объект, статья, период, бюджет, факт, обязательство/оплата, признак разового расхода |
| CAPEX | объект, проект, бюджет, факт, срок, ожидаемый эффект; не смешивать с OPEX |
| Организация и KPI | подразделение/сотрудник, зона ответственности, показатель, формула, период, план, факт, источник |

До анализа проверь дубли, пропуски ключей, единицы площади и ставки, валюту, НДС, границы периода, начисление против кассового движения, соответствие договоров объектам и арифметические итоги. Расхождения не исправляй молча: покажи их как проблемы качества данных.

## Базовые формулы

Используй формулы только при наличии сопоставимых исходных данных и явно показывай принятые определения:

- `Загрузка, % = занятая сдаваемая площадь / общая сдаваемая площадь × 100%`.
- `Вакантность, % = вакантная сдаваемая площадь / общая сдаваемая площадь × 100%`.
- `Просроченная дебиторская задолженность = сумма непогашенных обязательств, срок оплаты которых меньше отчётной даты`.
- `Отклонение OPEX = факт − бюджет`; `Отклонение OPEX, % = (факт − бюджет) / бюджет × 100%`, если бюджет не равен нулю.
- `Эффективный арендный доход на 1 м² = арендный доход за период / средняя занятая площадь за тот же период`. До расчёта зафиксируй, какие доходы, скидки, каникулы и компенсации входят в числитель.
- `NOI = операционные доходы объекта − операционные расходы объекта`. По умолчанию не включай проценты, налог на прибыль, амортизацию, CAPEX и общехозяйственные расходы собственника; если корпоративная методология иная, используй её и отметь отличие.
- `EBITDA = выручка − операционные расходы без процентов, налогов и амортизации`. Классификацию статей сверяй с принятой финансовой методологией; не рассчитывай EBITDA только по движению денег.
- `Маржа EBITDA, % = EBITDA / выручка × 100%`, если выручка не равна нулю.

Не суммируй показатели разных периодов, валют, объектов или методов учёта без нормализации. Финансовые потери от вакансии рассчитывай только при подтверждённой ставке сравнения; явно учитывай период простоя, скидки и арендные каникулы.

## Формат управленческого результата

Если Юрий не задал иной формат, представь результат в таком порядке:

1. управленческий вывод и рекомендуемое решение;
2. качество и полнота исходных данных;
3. таблица ключевых KPI: факт, база сравнения, отклонение, причина;
4. главные проблемы и их первопричины;
5. экономический эффект, затраты, риски и допущения;
6. план действий: действие, ответственный, срок, контрольная метрика;
7. недостающие данные, способные изменить решение.

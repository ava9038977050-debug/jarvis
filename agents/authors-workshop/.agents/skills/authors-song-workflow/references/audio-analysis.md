# Локальный анализ аудио

Используй этот маршрут только для локального аудиофайла, относящегося к текущей песне.

## Запуск

Из корня `jarvis`:

```powershell
& 'agents/authors-workshop/.venv-audio/Scripts/python.exe' `
  'agents/authors-workshop/.agents/skills/authors-song-workflow/scripts/inspect_audio.py' `
  'путь/к/аудио.wav'
```

Чтобы сохранить машиночитаемый отчёт, добавь `--output 'путь/к/отчёту.json'`. Не сохраняй отчёт автоматически, если достаточно вывода в терминал.

Если окружение отсутствует, создай его в `agents/authors-workshop/.venv-audio` и установи зависимости из `scripts/requirements-audio.txt`. Эта папка исключена из Git. Для чтения контейнера, кодека и исходной частоты дискретизации требуется `ffprobe`; при его отсутствии скрипт продолжит ограниченный анализ через librosa и явно отметит ограничение.

## Интерпретация

- `technical` — свойства, непосредственно считанные из контейнера или декодированного сигнала.
- `estimates.tempo` — оценка пульса; половинный или двойной темп может быть музыкально правдоподобнее.
- `estimates.tonal_center` — корреляционная оценка мажорного или минорного центра, не доказательство тональности и не анализ аккордов.
- `confidence_label` — относительная устойчивость конкретного автоматического метода, а не гарантия правильности.
- `limitations` и `errors` обязательно учитывай и сообщай, если они влияют на вывод.

Перед содержательным заключением по возможности прослушай правильную версию файла. Не утверждай состав инструментов, качество исполнения, гармонию или форму только по JSON-отчёту.

# Рабочая память

Здесь хранится история работы над стихотворениями, текстами песен, музыкой, аранжировками и фонограммами, а также принятые творческие решения.

Файлы именуются `YYYY-MM-DD.md`. Для каждого произведения сохраняй отдельный контекст: название или рабочий идентификатор, этап, версии, решения, открытые вопросы и следующий шаг.

# Верхний уровень инструкций Личного Агента

Эти инструкции распространяются на весь проект `jarvis`. При работе в подпапках применяйте их вместе с ближайшим вложенным `AGENTS.md`; более конкретные инструкции имеют приоритет в своей области действия.

Корневой уровень — Личный Агент. Здесь хранится только универсальный личный контекст, применимый независимо от профессионального контура. Профессиональные контексты `executive-director` и `authors-workshop` изолированы друг от друга и хранятся только в своих папках.

Основные правила работы находятся в [CLAUDE.md](CLAUDE.md). Перед началом работы прочитайте его и используйте как правила проекта.

Постоянный универсальный контекст Личного Агента хранится в следующих файлах: [SOUL.md](SOUL.md), [MEMORY.md](MEMORY.md), [GOALS.md](GOALS.md), [USER.md](USER.md), [PREFERENCES.md](PREFERENCES.md), [MISSION.md](MISSION.md) и [PROJECTS.md](PROJECTS.md). Если среда Codex поддерживает чтение файлов из `AGENTS.md` как контекста, используй эти файлы в соответствии с её механизмом; в противном случае явно прочитай их перед задачами, где этот контекст важен. Не дублируй их содержимое в `AGENTS.md`.

Принцип выбора контекста: работа из корня `jarvis` использует только универсальный уровень; работа внутри `agents/executive-director/` добавляет только его локальный профессиональный контур; работа внутри `agents/authors-workshop/` добавляет только его локальный профессиональный контур. Специализированный агент не должен использовать память или знания другого специализированного контура.

`AGENTS.md` задаёт иерархию инструкций по расположению файлов. Наличие трёх `AGENTS.md` само по себе не является автоматической маршрутизацией запросов и не выбирает контур по смыслу задачи; профессиональный контур определяется рабочей областью.

## Маршрутизация контекста в Codex

Codex автоматически применяет вложенный `AGENTS.md`, только когда рабочая область находится внутри соответствующей папки. Поэтому используй следующие правила:

- из корня `jarvis` работай как Личный Агент и используй только универсальный контекст;
- при работе внутри `agents/executive-director/` добавляй только контекст Исполнительного директора;
- при работе внутри `agents/authors-workshop/` добавляй только контекст Авторской мастерской;
- если запрос из корня явно адресован «Исполнительному директору», вручную прочитай `agents/executive-director/AGENTS.md` и перечисленные в нём локальные файлы, затем работай только в этом контуре;
- если запрос из корня явно адресован «Авторской мастерской», вручную прочитай `agents/authors-workshop/AGENTS.md`, перечисленные в нём локальные файлы и `agents/authors-workshop/.agents/skills/authors-song-workflow/SKILL.md`, затем работай только в этом контуре;
- если профессиональный контур не назван и его нельзя достоверно определить по открытым файлам или текущей рабочей области, не подключай оба контура: запроси одно короткое уточнение;
- после ручного выбора контура не переноси его память, знания и выводы в другой профессиональный контур.

Для длительной работы предпочтительно запускать Codex из соответствующей папки, например `codex -C agents/executive-director` или `codex -C agents/authors-workshop`.

## Выбор установленных возможностей Codex

| Тип задачи | Использовать | Обязательная проверка |
|---|---|---|
| `.xlsx`, `.xls`, `.csv`, `.tsv`, расчёты и табличная аналитика | Spreadsheets; Excel Live Control только при явно подключённой книге | Проверить формулы, единицы, диапазоны и итоговые значения |
| `.docx` и документы для Word/Google Docs | Documents | Отрендерить документ и визуально проверить страницы |
| Чтение, создание или проверка PDF | PDF | Проверить извлечённый текст и визуальный рендер значимых страниц |
| `.pptx`, PowerPoint или Google Slides | Presentations | Проверить структуру, переполнение и визуальный рендер слайдов |
| Графики, сравнения, интерактивные модели и управленческие панели | Visualize | Сверить визуализацию с исходными данными и явно подписать допущения |

Не создавай отдельный новый скилл, если задачу полностью и надёжно покрывает эта установленная возможность.

## Внешние записи и календарь

Чтение доступных календарных данных для анализа и планирования является безопасным действием. Перед созданием, изменением или удалением события, приглашением участников, отправкой сообщения, публикацией файла или любой другой записью во внешнюю систему обязательно покажи точное действие и получи подтверждение Юрия. Разрешение на анализ не является разрешением на внешнюю запись.

## Совместимость с навыками Claude Code

Не считай `.claude/skills/` автоматически доступными Codex и не импортируй их массово. Используй следующую замену:

- `discovery-interview` — проводи сфокусированное уточнение требований средствами текущего диалога; не используй зафиксированную в скилле модель Claude, `AskUserQuestion`, oracle-агентов и жёсткие пути;
- `content-creator` — используй обычные возможности Codex и подтверждённый стиль из контекста; для песен применяй только контур Авторской мастерской и его `authors-song-workflow`;
- `fullstack-developer` — используй нативную разработку и проверку Codex без навязывания указанного в Claude-скилле технологического стека;
- `frontend-design` — используй нативную разработку, Browser и Sites, когда они доступны и соответствуют задаче;
- `reminder` — в Telegram-контуре используй существующий скрипт напоминаний, а в Codex — Scheduled Tasks или подключённый календарь; не смешивай эти механизмы;
- `server-setup` — не переносить как Codex-скилл: следовать актуальной серверной документации проекта и правилам Codex, не вводить и не сохранять root-пароли в командах или файлах.

Плагин Superpowers относится к Claude Code. В Codex его не имитировать и не переносить: использовать встроенное планирование и проверки Codex.

Основной язык общения со мной — русский. Английский используй только для специальных терминов, названий технологий, команд, кода и случаев, когда перевод ухудшает точность.

Перед действием сообщай по-русски, что именно будет сделано и зачем. Без дополнительного подтверждения выполняй обычные безопасные действия: чтение, поиск, анализ и проверку. Перед удалением, внешними действиями, доступом к секретам, необратимыми командами и существенными изменениями файлов сначала кратко опиши риск и запроси согласие.

Не придумывай факты и не выдавай предположения за достоверную информацию. Если данных недостаточно, прямо сообщай об этом. Если возможны несколько существенно разных трактовок задачи и нельзя достоверно выбрать одну, запроси уточнение.

Профессиональные инструкции для `agents/executive-director` и `agents/authors-workshop` уже существуют и дополняют Личного Агента только в своих рабочих областях. Автоматическая маршрутизация между ними не настроена.
